NumPy: one grid, three axes, zero loops

An ndarray is a rectangular block of same-typed numbers. ndim says how many nested grids, shape gives rows×columns, size is the cell count, dtype is the single type every cell must share. Columns are axis 0, rows are axis 1 — the part that trips everyone.

np.array([[1,2,3],[3,4,5]])
Edit the grid, then pick an operation

Why not a plain list? — his timing demo

Same 1,000 numbers added together: the list loop took 208 ms, the ndarray took 67 ms. a1 + a2 is vectorised; l1 + l2 glues the two lists together instead of adding pairs.

What machine learning actually is

    
His honest admission: "ask 100 people and you'll get 100 definitions — there is no specific definition for machine learning yet." Arthur Samuel, 1959, gave the first formal one. The engineering version the course uses: an algorithm is trained on a training data set to produce a model; the model predicts on new input; the prediction is checked for accuracy; if it is not acceptable, the algorithm is trained again.

    data → model → prediction → check → retrain


  
Walk the loop — press next and watch which box is alive
    

    

    

  


  

    
supervised
Learning with a teacher
The training set has labels. He compares it to a child with a guide: the labelled data set is the teacher. His picture example: labelled duck photos train a predictor that can say duck / not duck on a new image. Algorithms: linear regression, logistic regression, decision tree, random forest, SVM, KNN. Uses: Cortana and phone voice training, the weather app, predicting faulty attributes on a production line.

    
unsupervised
No output column at all
You give data with no answer key; the algorithm applies its own structure and cannot name what it found. He stresses this: it can make three clusters but has no idea what a cluster means. Algorithms: K-means, hierarchical clustering, Apriori, PCA. Uses: market segmentation, normal-vs-abnormal medical images, collaborative filtering for recommendations.

    
reinforcement
Hit and mistake
No data set — an agent acts in an environment and receives a reinforcement signal. His numbers: reward for the right move, −50 points for a wrong one. Pavlov training a dog is his analogy. Uses: AlphaGo, self-driving cars, game playing, dynamic pricing, call-centre models.

  

  
Also in this chapter: semi-supervised = supervised + unsupervised — a small labelled part and a large unlabelled part (the X-ray case, where labelling is expensive). And the confusion he clears up with the Turing test: AI is the goal, ML is the method, deep learning is ML with neural nets that only became possible once computing could be parallelised.

Station 09 · mathematics · calculus & optimisation
The derivative, and the gradient descent that runs on it

    
Why an ML course spends an hour on calculus: a model is an equation, and training means changing its numbers until the error is smallest. The derivative tells you which way is down. His exact demo: input 0.1, target 0.3, a sigmoid, and a weight starting at 0.50 that only becomes 0.30 after enough iterations.

    f(x)=3x² → f'(x)=6x · 3x²+5x → 6x+5

The rules he used
Power rule — bring the exponent down, subtract 1: 3x² → 3·2x = 6x.
Sum rule — term by term: 3x²+5x → 6x+5.
Product rule — (x₁x₂)' = x₁'x₂ + x₂'x₁.
Constant rule — anything you are not differentiating behaves like a constant.

    
Partial derivatives
His three-variable example f = x² + 3y + 4xz²:
∂f/∂x = 2x + 4z²
∂f/∂y = 3
∂f/∂z = 8xz
"Keep everything else constant" — that is the whole technique, and it is what a gradient is.

    
Jacobian & Hessian
Differentiate a vector once and arrange the results as a matrix → Jacobian. Differentiate twice → Hessian (curvature, used by deeper optimisers). Plain gradient descent only needs the first-order object: one slope per parameter.

  


  

    
Python — gradient descent exactly as he typed it
import numpy as np

sigmoid = lambda x: 1 / (1 + np.exp(-x))

x, target = 0.1, 0.3
w    = np.array([0.5])      # the only number we may change
lr   = 0.1                  # learning rate

for epoch in range(10000):
    pred = sigmoid(x * w[0])
    err  = (pred - target) ** 2              # cost
    grad = 2*(pred - target) * pred * (1-pred) * x
    w[0] -= lr * grad                       # step downhill

print(w[0], sigmoid(x * w[0]))

    
His reported numbers
epochs =    10  ->  output ~ 0.47
epochs =   1000  ->  output ~ 0.36
epochs = 10000 ->  output   0.30000002   (target 0.3)

10 steps barely moved the weight; 10 000 landed on the
target. Same code, one number changed - which is why
"number of iterations" is a hyperparameter you tune.

Push the learning rate too high and the walker jumps
clean over the bowl and diverges: the other thing he

def entropy(counts):
    n = sum(counts)

Python — slope and intercept from the formula, not from sklearn
import numpy as np

x = np.array([1,2,3,4,5,6,7])
y = np.array([1,3,4,6,8,9,11])

m = (np.mean(x*y) - np.mean(x)*np.mean(y)) / \
     (np.mean(x**2) - np.mean(x)**2)
c = np.mean(y) - m * np.mean(x)
print(m, c)                     # his: ~1.5 and ~0.3
print(m * 8 + c)                 # ~12.45  -> "about 13"

yhat = m*x + c
sse  = np.sum((y - yhat)**2)       # the thing being minimised
sst  = np.sum((y - np.mean(y))**2)
print(1 - sse/sst)               # R^2

1. compute the slope m from the x and y values
2. compute the y-intercept c  (the point the line
   crosses the y-axis)
3. put m and c into y = mx + c and substitute the
   x you care about

His worked answer: m ~ 1.5, c ~ 0.3, so at a price of

Why accuracy lies — the fraud case he gives
      
"You will have millions of rows and only a tiny percentage will actually be fraud. Your model accuracy will mostly be higher — and it means nothing." Accuracy is a subset of model performance, not the whole of it: which error costs you more (false positive in spam, false negative in a disease test) decides whether you optimise precision or recall. His advice for the interview: define that beforehand, then tune the probability cutoff — default 0.5, try 0.8, and compare.
