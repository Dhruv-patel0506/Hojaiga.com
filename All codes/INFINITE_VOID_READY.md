## 🔧 Troubleshooting

### **Server won't start:**
- Make sure `infinite_void_server.py` exists
- Check Python is installed
- Check port 8765 is not in use

### **HTML won't open:**
- Make sure `infinite_void_react.html` exists
- Check your default browser is set

### **No connection:**
- Make sure server is running
- Check firewall isn't blocking port 8765
- Refresh the browser page
