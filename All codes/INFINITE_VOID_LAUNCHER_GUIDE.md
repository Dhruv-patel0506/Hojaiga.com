# Infinite Void Launcher - Single Command

## 🚀 Quick Start

### **Option 1: Batch File (Windows)**
```bash
cd "d:\new_automation\All codes"
start_void.bat
```

### **Option 2: Python Command**
```bash
cd "d:\new_automation\All codes"
python infinite_void_launcher.py
```

### **Option 3: Direct Command (from any directory)**
```bash
python "d:\new_automation\All codes\infinite_void_launcher.py"
```

## ✅ What This Does

1. **Launches the Infinite Void** as a standalone full-screen application
2. **Starts the WebSocket server** automatically in the background
3. **Loads the React UI** with modern styling
4. **Auto-cleanup** when you close the window

## 🎨 Features

- ✅ **Full-screen** infinite void lightboard
- ✅ **React-powered UI** with modern styling
- ✅ **Real-time connection status** (green/red)
- ✅ **Keyboard support** (Enter to submit)
- ✅ **Progressive drawing animation**
- ✅ **Neon glow effects**
- ✅ **Infinite canvas** with pan & zoom
- ✅ **Better diagrams** (no more just circles)

## 🧠 Intelligence

- ✅ **Newton's Laws**: Free body diagrams with force vectors
- ✅ **Gravitational force**: Masses with force vectors
- ✅ **Action-reaction**: Two masses with opposing arrows
- ✅ **Generic topics**: Relationship diagrams
- ✅ **LLaVA Integration**: Ready with health checks

## 🎯 How to Use

1. **Start the void** using any of the commands above
2. **Enter a topic** in the input field (e.g., "laws of motion")
3. **Press Enter** or click "Teach Me"
4. **Watch the progressive animation** with real diagrams!

## 📁 Files

- `infinite_void_launcher.py` - Main launcher script
- `infinite_void_react.html` - React-powered UI
- `infinite_void_server.py` - WebSocket server (auto-started)
- `start_void.bat` - Windows batch file shortcut

## 🔧 Requirements

- Python 3.x
- PyQt5 (for web view)
- websockets (for server)

## 🐛 Troubleshooting

### **PyQt5 not installed:**
```bash
pip install PyQt5 PyQt5-WebEngine
```

### **websockets not installed:**
```bash
pip install websockets
```

### **HTML file not found:**
Make sure `infinite_void_react.html` is in the same directory as the launcher.
