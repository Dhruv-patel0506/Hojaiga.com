2. NumPy: arrays for fast maths

NumPy stores numbers in arrays. Operations apply to every element at once, with no loop needed. This is the base for almost every other library here.

import numpy as np

3. Pandas: tables (DataFrames)

A DataFrame is a table with named columns. Machine learning datasets usually arrive as one, and you split it into features (inputs, X) and the target (output, y).

import pandas as pd
df = pd.DataFrame({"hours": [1, 2, 3, 4], "passed": [0, 0, 1, 1]})
X = df[["hours"]]     # features
y = df["passed"]      # target
print(df.shape)

6. The maths you will meet

  • Error: prediction minus true value.
  • Mean squared error (MSE): average of the squared errors. Lower is better.
  • Gradient: the slope of the loss. Stepping against it moves downhill.
  • Probability: numbers between 0 and 1. Bayes' rule updates a probability with new evidence.
  • Distance: Euclidean distance between points, the square root of summed squared differences.

7. Linear regression and gradient descent

A line y = w·x + b is fitted by making the MSE as small as possible. Use the sliders to fit by hand, or let gradient descent walk downhill on its own.

from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X, y)
print(model.coef_, model.intercept_)   # slope w and intercept b

Gradient step: w ← w − lr × ∂MSE/∂w, and b is updated the same way. Each step moves both values a little toward the lowest loss.

8. Logistic regression for classification

Logistic regression feeds a straight-line score into the sigmoid, which squashes any number into a probability between 0 and 1. Predict class 1 when the probability is at least 0.5.

weight w
bias b 
from sklearn.linear_model import LogisticRegression
clf = LogisticRegression().fit(X, y)
print(clf.predict_proba(X)[:3])

9. Decision trees

A tree asks a question at each node, such as "is hours ≤ 5?", and splits the data. A good split leaves each side as pure as possible. Impurity is measured with Gini: 0 means pure, 0.5 means a 50/50 mix.

threshold 
from sklearn.tree import DecisionTreeClassifier
tree = DecisionTreeClassifier(max_depth=3).fit(X, y)

10. Random forest

A forest trains many trees, each on a bootstrap sample: rows drawn with replacement. Rows never drawn are "out-of-bag". The forest's prediction is the majority vote of all trees.

from sklearn.ensemble import RandomForestClassifier
forest = RandomForestClassifier(n_estimators=100).fit(X, y)

14. K-means clustering

K-means picks k centres, assigns each point to its nearest centre, moves each centre to the mean of its points, and repeats until nothing changes.

from sklearn.cluster import KMeans
km = KMeans(n_clusters=2, random_state=0).fit(X)
print(km.labels_)

15. Hierarchical clustering

Hierarchical clustering starts with every point alone and repeatedly merges the two closest clusters. Single linkage measures the distance between clusters by their closest members.

from sklearn.cluster import AgglomerativeClustering
hc = AgglomerativeClustering(n_clusters=2, linkage="single").fit(X)

Support is the fraction of transactions containing an itemset. Apriori keeps only itemsets whose support meets a minimum, and it only extends sets that were already frequent.
