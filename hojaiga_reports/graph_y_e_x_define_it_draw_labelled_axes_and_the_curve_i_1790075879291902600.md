### Define the Function

Let's start by defining the function y = e^(-x). This function represents an exponential decay where the base is the mathematical constant e, approximately 2.71828, and the exponent is the negative of x. As x increases, y decreases, approaching zero but never reaching it. This is a classic example of an exponential function.

- **Explanation:** The function y = e^(-x) is an exponential decay function.
- **Equation:** y = e^(-x)
- **Result:** This function describes how y decreases as x increases, with y approaching zero but never reaching it.
