# TypeScript: TS Playground  (typescriptlang.org/play)

The Playground lets you write TypeScript or JavaScript online in a safe and sharable way.

## How to use it

- TypeScript: TS Playground: The Playground lets you write TypeScript or JavaScript online in a safe and sharable way.
- Main navigation: Skip to main content, TypeScript, Download, Docs, Handbook, Community, Playground, Tools, in En, TS Config.
- There is a search box on the page: that is the fastest way in.
- Menus / buttons that open something: TS Config, Examples, Help, Select version of TypeScript, currently 6.0.3, Plugins, v6.0.3, TypeScript Home Page, Docs.
